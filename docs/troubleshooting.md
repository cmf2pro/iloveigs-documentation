# Troubleshooting

This guide covers common problems when working with browser-based CAD viewing workflows.

## The File Does Not Open

Check that:

- The file extension is supported by the current application.
- The file is not corrupted.
- The file can be opened by another CAD or validation tool when appropriate.
- Your browser is up to date.

## The Model Looks Incorrect

Try:

1. Fitting the model to the viewport.
2. Switching between standard views.
3. Changing the display mode if available.
4. Reloading the file.

CAD exchange files can contain complex geometry, and results can vary depending on the source system and model construction.

## The Viewer Is Slow

Large or highly detailed models can require substantial browser resources. Closing unnecessary tabs and using a modern desktop browser may improve the experience.

## Measurements Need Verification

For manufacturing-critical work, do not rely on a single viewer measurement. Verify important dimensions against the authoritative CAD model, drawing, or engineering specification.
