# STEP Files: A Practical Guide

## What Is STEP?

STEP is a widely used CAD data exchange standard based on ISO 10303. Common file extensions include `.step` and `.stp`.

STEP is commonly used to transfer 3D product and engineering data between CAD systems.

## Viewing STEP Files

[iLoveIGS](https://www.iloveigs.com/) provides a browser-based workflow for supported STEP files.

A typical inspection workflow is:

1. Open iLoveIGS.
2. Load the STEP file.
3. Fit the model to the viewport.
4. Inspect the model using standard views.
5. Measure or create drawing views using available tools.

## STEP vs IGES

STEP generally provides a more structured modern exchange format for many product-development workflows, while IGES is still encountered frequently in existing engineering and legacy CAD data.

The best format depends on the originating CAD system, downstream requirements, and the type of information that must be transferred.
