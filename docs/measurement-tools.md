# CAD Measurement Tools

Measurement is a key part of CAD inspection and manufacturing review.

[iLoveIGS](https://www.iloveigs.com/) includes measurement-oriented workflows for supported model inspection.

## Point-to-Point Measurement

A point-to-point measurement workflow can be used to examine the distance between two selected points.

Depending on the active tool, useful results can include:

- 3D distance
- Delta X
- Delta Y
- Delta Z

## Practical Uses

CAD measurements can help with:

- Quick geometry verification
- Manufacturing review
- Model inspection
- Comparing expected and actual geometry
- Understanding feature locations

## Bounding Dimensions

Overall model dimensions can also be useful for quickly understanding the approximate X, Y, and Z envelope of a part.

## Measurement Best Practices

- Select points carefully on the intended geometry.
- Confirm the model orientation before interpreting Delta X, Y, and Z.
- Use multiple measurements when checking an important dimension.
- Treat viewer measurements as an inspection aid and verify critical manufacturing dimensions against the authoritative engineering data.
