# Technical Drawing and Drafting

Technical drawings communicate manufacturing and engineering information through standardized views, dimensions, notes, and title-block information.

[iLoveIGS](https://www.iloveigs.com/) includes a drafting-oriented workflow for supported models.

## Typical Drawing Views

A technical drawing may use:

- Front view
- Top view
- Right-side view
- Isometric view

## Drawing Layout

The drafting workspace can arrange model views on a drawing-sheet layout and may include:

- Drawing borders
- View placement
- Overall dimensions
- Title-block information
- Print-oriented layout

## From 3D Model to Drawing

A common workflow is:

1. Load the 3D model.
2. Inspect the geometry.
3. Select appropriate standard views.
4. Arrange the views on the drawing sheet.
5. Review dimensions and title-block information.
6. Print or export using the features available in the current application.

## Important Note

Automatically generated drawing views and dimensions should be reviewed by a qualified person before being used as manufacturing documentation. Critical dimensions should always be checked against the authoritative design requirements.
