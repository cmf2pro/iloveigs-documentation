# Getting Started with iLoveIGS

[iLoveIGS](https://www.iloveigs.com/) is a browser-based CAD viewer and drawing workspace for inspecting supported engineering files.

## Quick Start

1. Open [iLoveIGS](https://www.iloveigs.com/).
2. Select the appropriate file/viewer workflow.
3. Load a supported CAD or drawing file.
4. Inspect the model using standard views, orbit, pan, and zoom.
5. Use measurement and drafting tools when available.

## Typical Use Cases

- Quickly reviewing a CAD model
- Checking overall model dimensions
- Inspecting geometry before manufacturing
- Reviewing engineering drawings
- Comparing a model from standard views

> Available features and supported formats may change over time. Use the live application for the current feature set.
