# 🚀 Getting Started with iLoveIGS

**iLoveIGS** is a browser-based CAD viewer and technical drawing workspace for inspecting supported engineering files without requiring a traditional desktop CAD installation.

🌐 **Open iLoveIGS:** https://www.iloveigs.com/

> 💡 **Tip:** The live application is the best place to check the currently supported formats and features because the platform is continuously evolving.

---

## 📱💻 Works Across Modern Devices

iLoveIGS is designed for browser-based access across:

- 📱 Mobile phones
- 📲 Tablets
- 💻 Laptops
- 🖥️ Desktop workstations

For detailed 3D inspection of large or complex models, a larger screen and more capable hardware will generally provide a better experience.

---

## 1️⃣ Open the Application

Visit **[iLoveIGS](https://www.iloveigs.com/)** in a modern browser.

No traditional CAD installation is required to access the browser-based viewer.

Common modern browsers include:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Apple Safari

Browser capabilities, especially WebGL and available memory, can affect 3D performance.

---

## 2️⃣ Load a CAD or Drawing File

Depending on the current application workflow, a supported file can be loaded using the file-open interface or other available loading controls.

Typical formats covered by this documentation include:

| Format | Extensions | Typical purpose |
| :--- | :--- | :--- |
| **IGES** | `.igs`, `.iges` | CAD geometry exchange |
| **STEP** | `.step`, `.stp` | 3D product/CAD exchange |
| **STL** | `.stl` | 3D mesh data |
| **DXF** | `.dxf` | 2D CAD drawings |
| **DWG** | `.dwg` | CAD drawing data |
| **PDF** | `.pdf` | Technical documents/drawings |

> ⚠️ A file extension alone does not guarantee that every entity or feature inside a file will be interpreted identically across CAD systems.

---

## 3️⃣ Understand the Viewer

A typical CAD inspection workflow may include:

### 🎛️ Viewer / Toolbar Area

Provides access to major actions such as opening files, fitting the model, measuring, sharing a view, and entering drafting workflows where available.

### 🧭 View Controls

Use standard engineering views to understand the model from predictable orientations.

### 🧊 3D Viewport

The central area where the model is displayed and inspected.

### 📏 Measurement Information

When measurement tools are active, relevant dimensional information can be displayed for the selected geometry.

### 📝 Drafting Workspace

Where supported, the drafting workflow provides a 2D representation of the model for technical communication and printing.

> Interface labels and placement may change as iLoveIGS is improved.

---

## 4️⃣ Basic Model Navigation

For desktop mouse workflows, common CAD-style navigation may include:

| Action | Typical control |
| :--- | :--- |
| Select | Left click |
| Pan | Middle-button drag |
| Orbit | Right-button drag |
| Zoom | Mouse wheel |
| Fit | Fit command or available shortcut |

See the complete [CAD Viewer Controls](cad-viewer.md) guide for more detail.

On touch devices, available interaction can depend on the browser, screen size, and current application implementation.

---

## 5️⃣ Inspect the Model

A good first inspection sequence is:

1. 🔍 Fit the model to the viewport.
2. 🧭 Check Front, Top, Right, and Isometric views.
3. 🌀 Orbit around the model.
4. 🧊 Change the display mode if useful.
5. 📏 Measure important geometry.
6. 📐 Review overall dimensions.
7. 📝 Enter the drafting workflow when a drawing reference is needed.

This sequence is useful for a quick manufacturing or engineering review before deeper CAD work.

---

## 6️⃣ Verify Important Information

A browser viewer is an inspection aid. For manufacturing-critical work, verify important dimensions and requirements against the controlled CAD model, engineering drawing, specification, or other authoritative source.

This is particularly important when:

- The model came from a third-party CAD system.
- The file contains complex surfaces.
- A conversion was performed before viewing.
- Tolerances are important.
- The geometry will be used directly for manufacturing decisions.
