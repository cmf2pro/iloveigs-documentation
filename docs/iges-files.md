# IGES Files: A Practical Guide

## What Is IGES?

IGES (Initial Graphics Exchange Specification) is a CAD data exchange format used to transfer geometric and drawing information between engineering software systems.

Common IGES extensions are `.igs` and `.iges`.

## Opening an IGES File

You can use the [iLoveIGS online CAD viewer](https://www.iloveigs.com/) to work with supported IGES files directly in a web browser.

A typical workflow is:

1. Open iLoveIGS.
2. Choose the relevant CAD viewing workflow.
3. Load the `.igs` or `.iges` file.
4. Inspect the geometry using standard views.
5. Use available measurement or drafting tools as required.

## IGES in Manufacturing

IGES remains useful when exchanging CAD geometry between different systems, particularly in workflows involving legacy data and surface geometry.

## IGES vs STEP

IGES and STEP are both CAD exchange standards, but they are designed around different data models and capabilities. For a modern product-data workflow, STEP is often preferred when richer product information and structured data exchange are required.
