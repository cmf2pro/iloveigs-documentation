# STL Files

STL is a common 3D mesh format used in applications such as rapid prototyping, 3D printing, visualization, and manufacturing workflows.

Common extensions are `.stl`.

## STL vs CAD Exchange Formats

Unlike STEP and IGES, STL primarily represents geometry as a triangular mesh. It does not provide the same type of parametric or feature-level CAD information found in many native or exchange CAD models.

## STL Inspection

When supported by the current iLoveIGS application, STL files can be useful for browser-based visual inspection and understanding the overall shape and size of a mesh model.
