# 🎨 Documentation Assets

This directory contains visual resources used by the documentation.

## Recommended structure

```text
assets/
├── screenshots/
├── diagrams/
├── icons/
└── social/
```

Use descriptive filenames and keep images optimized for the web.

Example:

```text
assets/screenshots/iloveigs-cad-viewer.png
assets/screenshots/measurement-workflow.png
assets/diagrams/iges-vs-step.svg
```

When adding screenshots, avoid including confidential customer CAD data or personally identifiable information.
